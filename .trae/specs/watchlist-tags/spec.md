# 观察仓标签功能规范

## 一、功能概述

**问题/机会**：用户需要更好地组织和分类观察仓股票，当前所有观察仓股票混杂在一起，难以快速找到特定类型的股票。

**解决方案**：为观察仓添加自定义标签功能，允许用户创建、编辑、删除标签，并将标签分配给观察仓股票。同时支持通过点击标签快速筛选对应的股票。

## 二、数据存储方案

### 2.1 方案选择：简化独立表方案

| 方案 | 表数量 | 推荐度 |
|------|--------|--------|
| 原方案B（3表） | user_tags + stock_tags + user_data | 中 |
| **简化方案（2表）** | user_tags + user_data | ✅ **推荐** |

**简化方案优势**：
- 减少一张表
- 查询观察列表时直接拿到标签，无需额外 JOIN
- 数据更紧凑

### 2.2 数据库表设计

#### 表1：user_tags（用户标签定义表）

```sql
CREATE TABLE user_tags (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT NOT NULL,
    name TEXT NOT NULL,
    color TEXT NOT NULL DEFAULT '#409EFF',
    is_preset INTEGER DEFAULT 0,
    is_enabled INTEGER DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_id, name)
);

CREATE INDEX idx_user_tags_lookup ON user_tags(user_id, is_enabled);
```

#### user_data 表扩展（观察列表）

原有 `data_type = 'watchlist'` 的 `json_value` 格式从数组改为对象数组：

```json
// 旧格式（仅代码数组）
["sh600519", "sz300054"]

// 新格式（代码+标签对象）
[
  {"code": "sh600519", "tags": ["科技", "消费"]},
  {"code": "sz300054", "tags": ["化工"]}
]
```

## 三、数据迁移

### 3.1 迁移内容

1. **创建 user_tags 表**：新建标签定义表
2. **迁移 watchlist 格式**：将 `["code1", "code2"]` 转为 `[{"code": "code1", "tags": []}]`
3. **初始化预设标签**：为所有已有用户创建预设标签

### 3.2 迁移脚本

```python
# migrate_watchlist_tags.py
# 迁移脚本功能：
# 1. 创建 user_tags 表
# 2. 迁移所有用户的 watchlist 数据格式
# 3. 为已有用户初始化预设标签
```

### 3.3 迁移执行步骤

```
1. 备份 user_data.db 数据库
2. 运行迁移脚本: python migrate_watchlist_tags.py
3. 验证迁移结果
4. 启动服务
```

### 3.4 回滚方案（如需要）

## 四、API 设计

### 4.1 标签管理 API

```
GET    /api/watchlist-tags        # 获取用户的所有标签
POST   /api/watchlist-tags        # 创建新标签
DELETE /api/watchlist-tags/{name} # 删除标签
PUT    /api/watchlist-tags/{name} # 更新标签（启用/禁用）
```

### 4.2 观察列表 API 变更

```
GET    /api/watchlist             # 返回数据中包含 tags 字段
POST   /api/watchlist/{code}      # 创建时支持可选的 tags 参数
PUT    /api/watchlist-tags/{code} # 更新股票的标签
```

## 六、业务规则

1. **标签名称唯一性**：同一用户的标签名称不能重复
2. **标签名称长度**：1-20 个字符
3. **颜色选择**：6 种预设颜色
4. **删除标签影响**：删除标签时，该标签从所有观察仓的标签列表中移除
5. **筛选逻辑**：支持单个标签筛选
6. **预设标签管理**：预设标签不能删除，只能启用/禁用
7. **用户隔离**：标签数据按用户隔离
