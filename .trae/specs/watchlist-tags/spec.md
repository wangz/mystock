# 观察仓标签功能规范

## 一、功能概述

**问题/机会**：用户需要更好地组织和分类观察仓股票，当前所有观察仓股票混杂在一起，难以快速找到特定类型的股票。

**解决方案**：为观察仓添加自定义标签功能，允许用户创建、编辑、删除标签，并将标签分配给观察仓股票。同时支持通过点击标签快速筛选对应的股票。

## 二、变更内容

### 2.1 数据库变更

* 在 `user_data` 表中新增 `tags` 数据类型，存储用户的所有标签列表

* 在观察仓股票数据结构中增加 `tags` 字段，存储股票对应的标签列表

### 2.2 后端 API 变更

**新增 API 端点：**

1. `GET /api/watchlist-tags` - 获取用户的所有标签
2. `POST /api/watchlist-tags` - 创建新标签
3. `DELETE /api/watchlist-tags/{tag_name}` - 删除标签（同时从所有股票中移除该标签）
4. `PUT /api/watchlist-tags/{ticker}` - 为观察仓股票设置标签

**修改 API 端点：**

1. `GET /api/watchlist` - 返回数据中增加 `tags` 字段
2. `POST /api/watchlist/{ticker}` - 创建时支持可选的 `tags` 参数

### 2.3 前端变更

* 在观察仓面板添加标签管理区域

* 显示标签列表，支持创建和删除标签

* 观察仓股票列表中显示每只股票的标签

* 支持点击标签进行筛选，显示该标签下的所有股票

* 支持在添加股票时选择标签

* 支持在股票详情/编辑时修改标签

## 三、技术实现

### 3.1 数据结构设计

**标签列表存储（存储在 user\_data 表）：**

```json
{
  "tags": [
    {"name": "科技", "color": "#409EFF", "created_at": "2024-01-01T10:00:00"},
    {"name": "消费", "color": "#67C23A", "created_at": "2024-01-02T10:00:00"}
  ]
}
```

**观察仓股票数据结构变更：**

```json
{
  "code": "sh600519",
  "name": "贵州茅台",
  "tags": ["消费", "蓝筹"],
  "price": 1850.0,
  "change": 42.5,
  "change_percent": 2.35
}
```

### 3.2 API 详细设计

#### 3.2.1 获取标签列表

```
GET /api/watchlist-tags
Response:
{
  "tags": [
    {"name": "科技", "color": "#409EFF", "created_at": "2024-01-01T10:00:00"},
    {"name": "消费", "color": "#67C23A", "created_at": "2024-01-02T10:00:00"}
  ],
  "count": 2
}
```

#### 3.2.2 创建标签

```
POST /api/watchlist-tags
Body:
{
  "name": "新能源",
  "color": "#E6A23C"
}
Response:
{
  "success": true,
  "tag": {"name": "新能源", "color": "#E6A23C", "created_at": "2024-01-03T10:00:00"}
}
```

#### 3.2.3 删除标签

```
DELETE /api/watchlist-tags/{tag_name}
Response:
{
  "success": true,
  "message": "标签已删除"
}
```

#### 3.2.4 设置股票标签

```
PUT /api/watchlist-tags/{ticker}
Body:
{
  "tags": ["科技", "新能源"]
}
Response:
{
  "success": true,
  "code": "sh600519",
  "tags": ["科技", "新能源"]
}
```

#### 3.2.5 获取观察仓（带标签筛选）

```
GET /api/watchlist?tag=消费
Response:
{
  "watchlist": [
    {"code": "sh600519", "name": "贵州茅台", "tags": ["消费"], ...}
  ],
  "count": 1,
  "filter": {"tag": "消费"}
}
```

#### 3.3.7 标签筛选交互流程

**流程 1：点击标签管理区的标签**

1. 用户 hover 标签 → 显示删除按钮
2. 用户 click（非删除按钮区域）→ 设置筛选
3. 筛选指示器显示当前筛选标签
4. 观察仓列表更新，仅显示该标签下的股票
5. 标签管理区该标签显示选中状态（边框加粗）

**流程 2：清除筛选**

1. 用户 click 筛选指示器的 `×` 按钮
2. 筛选指示器消失
3. 观察仓列表恢复显示全部
4. 标签管理区标签恢复默认状态

**流程 3：点击股票列表的标签**

1. 用户 click 股票行的标签芯片
2. 该标签被筛选（如同点击标签管理区的标签）
3. 标签管理区该标签显示选中状态

## 四、业务规则

1. **标签名称唯一性**：同一用户的标签名称不能重复
2. **标签名称长度**：1-20 个字符
3. **颜色选择**：提供预设颜色供选择（6 种预设颜色）
4. **删除标签影响**：删除标签时，该标签从所有股票的标签列表中移除
5. **筛选逻辑**：支持单个标签筛选，显示该标签下的所有股票
6. **空标签处理**：股票的标签列表可以为空（表示未分类）
7. **用户隔离**：标签数据按用户隔离，未登录用户不显示标签功能
