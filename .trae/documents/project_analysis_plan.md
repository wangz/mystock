# MyStock 项目整体分析计划

## 一、项目概述

MyStock 是一个功能完整的智能股票分析助手，提供实时行情、打板分析、股东动态监控等核心功能。

**技术栈：**
- 前端：Vue 3 (Composition API) + Element Plus
- 后端：FastAPI (Python)
- 数据库：SQLite
- 认证：JWT
- 外部数据：腾讯API、同花顺问财、akshare

#### 🔴 严重问题

1. **前端文件过大**
   - 问题：`frontend/index.html` 文件超过 3500 行，代码难以维护
   - 建议：将代码拆分为多个组件文件

2. ~~**代码重复**~~ ✅ **已修复**
   - 问题：`main.py` 中有两处 `fetch_stock_data_async` 函数定义
   - 状态：已合并为单一定义（第 359 行）

3. ~~**DEBUG 日志遗留**~~ ✅ **已修复**
   - 问题：`auth.py` 和 `main.py` 中有 `print()` 语句
   - 状态：已完全清除所有 print 语句

4. ~~**前端 console.log 遗留**~~ ✅ **已修复**
   - 问题：前端代码中有 `console.log()` 调用
   - 状态：已完全清除

#### 🟡 中等问题

5. **数据库连接管理不规范**
   - 问题：多处直接使用 `conn = sqlite3.connect()` 而没有使用上下文管理器
   - 建议：使用 `with` 语句确保连接正确关闭

6. **CORS 配置过于宽松**
   - 问题：`main.py` 中 `allow_origins=["*"]`
   - 建议：在生产环境中限制为具体域名

7. ~~**依赖项不完整**~~ ✅ **已修复**
   - 问题：`requirements.txt` 中缺少 `bcrypt` 依赖
   - 状态：✅ 已添加 `bcrypt==4.1.2`

8. **缺乏输入验证**
   - 问题：某些 API 端点没有充分的输入验证
   - 示例：`search_stock` 接口的 `keyword` 参数没有长度限制
   - 建议：添加长度限制和特殊字符过滤

#### 🟢 轻微问题

9. **代码注释不一致**
   - 问题：中英文注释混用，缺乏统一风格
   - 建议：统一注释语言（建议使用英文或中文）

10. **错误处理不统一**
    - 问题：某些函数返回错误，某些抛出异常，不一致
    - 建议：统一错误处理方式

---

### 2.2 架构设计问题

11. **所有业务逻辑集中在 main.py**
    - 问题：后端代码大部分在 `main.py` 中（约 1650 行）
    - 建议：按功能拆分为多个模块（如 `routes/`, `services/`, `models/`）

12. **前端单文件应用过大**
    - 问题：所有前端代码在一个 HTML 文件中
    - 建议：拆分为 Vue 单文件组件（.vue）

13. **数据库表结构设计**
    - 问题：`user_data` 表使用 JSON 存储数据，查询效率低
    - 建议：考虑使用关系型表结构或文档数据库

14. **配置管理分散**
    - 问题：配置分散在多个文件中
    - 建议：统一使用 `.env` 文件管理配置

---

### 2.3 安全性问题

15. **JWT Secret 没有轮换机制**
    - 问题：JWT Secret 生成后持久化，但没有提供轮换机制
    - 建议：实现 Secret 轮换功能

16. **密码强度检查不够**
    - 问题：仅检查密码长度 >= 6
    - 建议：增加密码复杂度要求

17. **API 限流缺失**
    - 问题：没有实现 API 调用限流
    - 风险：可能被滥用或攻击

18. **敏感信息日志**
    - 问题：DEBUG 日志可能记录敏感信息
    - 建议：移除或脱敏处理

---

### 2.4 性能和可维护性

19. **股票数据批量获取**
    - 问题：虽然有批量获取函数，但某些场景可能仍逐个获取
    - 建议：确保所有场景使用批量获取

20. **缓存策略不一致**
    - 问题：不同 API 使用不同的缓存时长
    - 建议：统一缓存策略

21. **缺乏 API 版本控制**
    - 问题：API 没有版本控制
    - 建议：使用路径版本控制（如 `/api/v1/`）

22. **测试覆盖不足**
    - 问题：没有测试文件
    - 建议：添加单元测试和集成测试

---

### 2.5 文档问题

23. **API 文档不完整**
    - 问题：虽然 FastAPI 自动生成文档，但某些端点缺少说明
    - 建议：添加完整的 API 文档注释

24. **README 缺失部署说明**
    - 问题：README 缺少生产环境部署指南
    - 建议：添加 Docker 部署指南
